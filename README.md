### 專案簡介
一個簡單的單字紀錄程式:
|功能|函數名稱|簡單說明|
|---|---|---|
|測驗|`run_quiz()`|進行測驗，錯誤進行重測|
|成績|`show_summary()`|正確率與測試次數結算|
|分析|`show_word_progress()`|逐項單字正確率結算|
|加入|`add_word()`|加入新單字|
|刪除|`delete_word()`|刪除單字|
